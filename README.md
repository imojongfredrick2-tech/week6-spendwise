# SpendWise - Interactive Budget Tracker

SpendWise is an interactive budget tracking application that helps users manage their budgets and expenses. Set a budget, record expenses, and keep track of the remaining balance.

## Features

- Set a personal budget.
- Add expenses and choose their categories.
- View expense records in a table.
- Calculate total expenses and remaining budget.
- Delete expense records.
- Receive budget warnings.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## JavaScript Concepts

- **Variables:** Store the budget and reference HTML elements.
- **Arrays:** Store multiple expense records in an `expenses` array.
- **Conditional statements:** Validate expenses and check budget conditions.
- **Loops:** Calculate total expenses and display records.
- **DOM manipulation:** Update webpage content with methods such as `getElementById()`, `createElement()`, and `textContent`.
- **Event listeners:** Handle form submissions and delete button clicks with `addEventListener()`.

## How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Enter your budget.
5. Add expenses and monitor your balance.
