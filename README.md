# SpendWise Budget Tracker

## Project Description

SpendWise is an interactive budget tracking
application developed using HTML, CSS and JavaScript.

It helps users manage their budgets, record expenses
and monitor their remaining balances.

## Features

- Set a personal budget.
- Add multiple expenses.
- View expense records.
- Calculate total expenses.
- Monitor remaining balance.
- Delete expense records.
- Receive budget warnings.

## JavaScript Concepts Used

### 1. Variables
Used variables to store the budget and expense information.

### 2. Conditional Statements
Used if, else if and else to check budget conditions.

### 3. Arrays
Used arrays to store multiple expense records.

### 4. Loops
Used for loops to calculate and display expenses.

### 5. DOM Manipulation
Used JavaScript to update dashboard information dynamically.

### 6. Event Listeners
Used event listeners to respond to form submissions
and delete button clicks.

## Technologies

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a browser.
4. Set your budget.
5. Start adding expenses.
